

# Day 13: AI Resume Analyzer

## 📌 Description
This project is an AI-powered Resume Analyzer built using OpenAI API.
It analyzes resume text and provides insights such as skills, weaknesses, and improvement suggestions.

## 🚀 Features
- Analyze resume using AI
- Extract key skills
- Identify weak areas
- Provide improvement suggestions

## 🛠️ Technologies Used
- Python
- OpenAI API

## 📂 Files
- day13_resume_ai.py → Main code
  

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Set API key:
   export OPENAI_API_KEY="your_api_key"

3. Run the program:
   python3 day13_resume_ai.py

## 💡 How to Use
- Paste your resume text when prompted
- Get AI-generated analysis
